# RSA — 攻击决策树（题面 → 攻击）

> **用法**：拿到 `(n, e, c)` 和附件后，不要先想"该用哪个攻击"，先看**手上有哪些信息**。下面每一层按成本从低到高排；前两层通常 1 分钟内就能决定这题值不值得继续做。
> 原理与密钥生成看 [[RSA原理]]；本页只做路由，判据 + 做法 + 脚本都指向具体笔记。

## 零、起手三件事（30 秒，零成本）

1. **两两 `gcd(n_i, n_j)`** —— 只要给了两组以上公钥，永远先做这一步。
2. **`iroot(c, e)`** —— `e` 很小且 flag 短时，密文就是没取过模的干净整数幂。
3. **量三个数**：`e` 的位长、`d` 是否已知/很小、有没有多给一个参数（dp、d、φ、p 的位）。

## 一、按「你手上有什么」分五组

### A · 多组公钥 / 同模（成本几乎为 0，先做）

| 触发特征 | 攻击 | 笔记 |
| --- | --- | --- |
| 两个模数共享素因子，`gcd(n₁,n₂) > 1` | 两两 gcd，命中即分解两把 n | [[RSA11-共素数-gcd分解]] |
| 同一个 n、两个不同的 e（互素） | 共模：`s·e₁+t·e₂=1` → `m = c₁ˢ·c₂ᵗ`，不必分解 | [[RSA13-共模攻击]] |
| 同一明文广播给 ≥ e 个收件人，e 小 | CRT 合并得整数值 mᵉ，再开 e 次整数根 | [[RSA14-低指数广播攻击]] |
| 同 n、同 e，两密文对应相关消息 `m₂ = a·m₁+b` | Franklin-Reiter：`gcd(xᵉ−c₁, (ax+b)ᵉ−c₂)` | [[RSA15-相关消息-FranklinReiter]] |
| 因子不严格相等（p 与 next_prime(p) 之类） | 直接 gcd 会失败，用 rho 变体找碰撞 | [[RSA12-共素数-PollardRho变体]] |

### B · e / d 参数异常

| 触发特征 | 攻击 | 笔记 |
| --- | --- | --- |
| e 很小且 `mᵉ < n` | `iroot(c, e)` 直接出明文 | [[RSA14-低指数广播攻击]] |
| `e ≈ n`，d 很小（`d < n^0.25/3`） | Wiener：连分数展开 e/n，收敛子当 k/d 试 | [[RSA21-Wiener攻击]] |
| `0.25 < d < 0.292·n` | Boneh-Durfee（格）；只需认得边界，不必实现 | [[RSA21-Wiener攻击]] 第八节 |
| `gcd(e, φ(n)) ≠ 1` | 典型 e=2 的 Rabin 改法；分解后在 p、q 下各开 e 次根再 CRT | [[RSA22-e与phi不互素-开高次根]] |
| e 很小 + 已知明文高位前缀（`flag{`、padding） | 设 `m = m₀ + x`，对 `(m₀+x)ᵉ − c ≡ 0` 做一元 Coppersmith | [[RSA23-Coppersmith高位攻击]] 附一 |

### C · 题目泄漏了额外参数

换算原则：**每个泄漏量都要想办法变成 `p+q`、`φ(n)` 或 p 的若干位**。

| 触发特征 | 攻击 | 笔记 |
| --- | --- | --- |
| 给了 dp（或 dq、或两者） | `e·dp − 1 = k(p−1)`，k ∈ [1,e)，爆破 k 取 gcd | [[RSA31-dp泄露家族]] |
| 给了 d 或 φ(n) | φ → 解 `p+q = n−φ+1` 的二次方程；d → `ed−1 = kφ` 或随机 a 概率分解 | [[RSA33-d与phi泄露]] |
| 给了 p（或 q）的连续高位 / 低位，≥ 约一半比特 | 一元 Coppersmith（`p = p₀+x` 或 `p = x·2ᵏ+p₀`） | [[RSA23-Coppersmith高位攻击]] |
| 给了 d 的部分位（如低 1/4 比特） | Partial Key Exposure：模 2ᵏ 解 k 的低位，再 Coppersmith 补高位 | [[RSA23-Coppersmith高位攻击]] 附二 |
| 给了 `p+q`、`p−q`、`p⊕q` | 和差配 n 解二次方程；异或从低位逐位推，再 Coppersmith | [[RSA34-已知和差异或]] |
| 题目自造参数（n 由 φ 或其它量反推构造） | 把生成脚本的等式全写出来消元，通常落到二次方程或小根问题 | [[RSA32-构造A反推参数]] |

### D · n 自身的结构（没有任何泄漏时，看 p、q 怎么生成）

| 触发特征 | 攻击 | 笔记 |
| --- | --- | --- |
| p = q（n 是完全平方） | `isqrt(n)**2 == n` 就结束 | —（yafu 直接出） |
| p、q 相近：差值远小于 n 的平方根 | Fermat：从 `ceil(√n)` 起试 `a²−n` 是否平方 | [[RSA41-p,q相邻-Fermat分解]] |
| p−1 是 B-smooth | Pollard p−1，B 从 1e4 递增到 1e6 | [[RSA42-p减1光滑-Pollardp-1]] |
| p+1 是 B-smooth | Williams p+1（Lucas 序列版），p−1 失败后镜像试 | [[RSA43-p加1光滑-Williamsp+1]] |
| 三因子以上，其中某个小 | ECM 逐个小到大摘因子，别上通用分解 | —（yafu / ECM） |
| 素数由时间戳 / 固定种子 / next_prime 生成 | 复现随机数流，窗口内逐个 seed 生成候选 p 测整除 | [[RSA44-随机数缺陷-可预测素数]] |

### E · 兜底

1. ECM 递增曲线 → yafu：`cd D:\网络安全工具\yafu_avx2` 后跑 `yafu.exe "factor(n)"`（必须在该目录内；>95 位需要 ggnfs）。
2. **止损判据**：如果一条路径要求硬拆 500+ 位素数乘积，说明允许的算法不在这儿 —— 回去找第二条信息（多一组 n、多一个泄漏量、多一条等式），而不是换更强的分解器。

## 三、判定顺序（照这个走，别跳）

**A（gcd / 共模）→ 直接开方 → B（e、d、dp 是否异常）→ C（每个泄漏量换算成 p+q 或 p 的位）→ D（Fermat / p−1）→ E（yafu 兜底）**

前两层几乎总能在 1 分钟内给出"这题能不能做"的答案；先跑重工具再回头读题，是这类题最常见的浪费时间方式。
