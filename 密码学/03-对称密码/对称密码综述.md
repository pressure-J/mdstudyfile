## 0. 先分清两条主线（这一步错了后面全白做）

对称密码 = 加密和解密用**同一把密钥**。按"怎么处理明文"分两大类：

| | 流密码 | 分组密码 |
|---|---|---|
| 处理单位 | 逐位 / 逐字节 | 固定块（通常 16 字节） |
| 核心 | 密钥流生成器 + XOR | 轮函数 + S 盒 + 密钥扩展 |
| 代表 | RC4、LFSR / FCSR、A5/1 | AES、DES、SM4 |
| 安全命门 | 密钥流重用、生成器线性 | 模式选错、填充侧信道、结构可逆推 |
| CTF 考法 | 恢复密钥流 / 反推种子 | 利用模式缺陷 / 逆运算 / 抓实现错误 |

判断口诀：**逐字节异或 → 流密码；固定块长、块内整体变换 → 分组密码**。

---

## 路径 ① 流密码 → 密钥流就是一切

流密码不"加密"，只是把明文和密钥流逐位 XOR。**密钥流一重用、生成器一线性，整个密码就塌**——这是本层全部考点。

### 密钥流重用 → 两式相减
同一段密钥流加密两条消息：C1⊕C2 = M1⊕M2，所以有一组已知明文就能解出另一条。
**为什么**：XOR 对称且可逆，密钥流在两式里被消掉。
学到什么算过关：不看模板，独立写出 M2 = C1⊕C2⊕M1 并说清每一步在消什么。
→ 子笔记《流密码与密钥流安全》（待写）

### 循环异或 → 已知明文前缀推密钥周期
密钥很短、逐字节循环 XOR：明文前缀已知 → 直接抠出密钥前缀 → 看密钥流首尾是否重复定周期。
→ 子笔记《循环异或与周期分析》（待写）

### LFSR / FCSR → 线性系统恢复状态
LFSR 的输出是状态的线性组合 → 凑够输出位就是 GF(2) 线性方程组，解出初始状态（常就是 flag）。
FCSR 多个进位寄存器（非线性），但"冻住"进位后整个系统退化成线性 → 同一套解法。
→ 子笔记《LFSR状态恢复》（待写）、《FCSR线性化攻击》（待写）

## 路径 ② 分组密码结构 → 解密 = 逆着走一遍

分组密码把明文分块，用**轮函数**反复混淆扩散。考点是结构本身：

### 轮函数与 S 盒
混淆（S 盒换掉单个字节的值）+ 扩散（置换/线性层让一个字节的影响散开到全块）。
S 盒是唯一的非线性来源，本质是有限域求逆（AES 用 GF(2⁸) 上的 0x11B）。

### 密钥扩展与逆运算逻辑
主密钥扩展出一串轮密钥；**解密 = 轮密钥逆序 + 每步逆变换**。
密钥扩展通常可逆推：给部分轮密钥能反推主密钥。
学到什么算过关：能徒手讲清"解密时轮密钥为什么倒着用"，给 S 盒能求逆表。
→ 子笔记《分组密码结构与逆运算》 ✅ 2026-10-24 已写（C1/C2/C3 例题复盘）

## 路径 ③ 工作模式 → 结构缺陷全在这一层

分组密码只定义了"16 字节 → 16 字节"，怎么加密长消息靠**工作模式**。算法本身很强，模式用错全白搭——考题九成出在这。

### ECB → 块重复泄露结构
相同明文块 → 相同密文块。不用解密就能看出重复、挪块、拼块（改权限的经典手法）。

### CBC → 比特翻转
改密文上一块的一个比特 → 下一块明文对应比特翻转（代价：上一块明文被毁）。
IV 可预测 / 可控也是同层考点。

### CTR / OFB → 密钥流重用 = 流密码事故
两者都把分组密码变成"生成密钥流再 XOR"：CTR 加密计数器，OFB 迭代加密 IV。
**计数器 / IV 重用 → 同一段密钥流加密两条消息 → 退化成路径①的重用题。**

### Padding Oracle → 不解密也能逐字节剥明文
解密端"报不报填充错误"本身就是侧信道。CBC 下逐字节构造，每字节最多 256 次尝试。
学到什么算过关：拿到密文先切块找重复；看到"同 key 同 IV/nonce"立刻想到密钥流重用。
→ 子笔记《工作模式与配置缺陷》 ✅ 2026-10-22 已写｜《填充与Padding-Oracle》（待写）

## 路径 ④ 国密对称算法实现 → 工程层找错

SM4 结构与 AES 同层，考点不在数学，在**实现**：
- 算法标识码 / 接口常量用错（如 `SGD_SM4_CBC` 一类）
- OFB 计数器错误地写进 IV
- 密钥硬编码、密钥复用、错误填充不校验

| 现象 | 先想什么 |
|---|---|
| 两段密文 XOR 出可读内容 / 有已知明文对 | 密钥流重用（路径①，或 CTR/OFB 重用） |
| 密文里出现重复块 | ECB |
| 改密文一处、明文另一处跟着变 | CBC 比特翻转 / XOR 可篡改性 |
