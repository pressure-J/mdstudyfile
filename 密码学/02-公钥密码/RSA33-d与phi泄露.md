# RSA — d 与 φ(n) 泄露（两条分解路径）

## 题型识别（一眼看出）

- 题面直接给了 `φ(n)`，或给了完整的 `d`（有时藏在"私钥文件"里）；
- 常见于：只给 `(n, e, d)` 要求求 `p, q`，或给了 `d` 但密文被另一套密钥加密。

> **先问一句：手上有 `c` 吗？** 有 `c` + 完整 `d` 就直接 `pow(c, d, n)`，不必分解。分解只在你需要 `p, q` 时做（打同模数的其他密钥、伪造签名、题目直接要因子）。这一步没想清楚会白算十分钟。

## 原理一：φ(n) 泄露 → 一次二次方程

$$
\varphi(n) = (p-1)(q-1) = pq - p - q + 1 = n - (p+q) + 1
$$

即

$$
p + q = n - \varphi(n) + 1 =: s
$$

配合 `p·q = n`，`p, q` 是 `x² − s·x + n = 0` 的两根：

$$
p,q = \frac{s \pm \sqrt{s^2 - 4n}}{2},\qquad (p-q)^2 = s^2-4n \text{ 必为完全平方}
$$

## 原理二：d 泄露 → 平方链 + gcd（概率分解）

`ed ≡ 1 (mod φ)` ⇒ `t = ed − 1` 是 `φ(n)` 的倍数 ⇒ 任意 `a` 都有 `a^t ≡ 1 (mod n)`。

把 `t` 写成 `t = 2ˢ·r`（r 奇），看平方链 `a^r, a^2r, …, a^t`：模 p 和模 q 两个分量**落到 1 的步数大概率不同**，当一边已是 1、另一边还是 −1 时，`gcd(a^(2ʲ r) − 1, n)` 就分出一个因子。命中率 ≥ 1/2，失败（gcd 退化成 1 或 n）换随机 `a` 重来。

```python
def from_phi(n, phi):
    s = n - phi + 1
    d = s*s - 4*n
    r = isqrt(d); assert r*r == d
    return (s - r)//2, (s + r)//2

def from_d(n, e, d):
    t = e*d - 1
    s = (t & -t).bit_length() - 1      # t 中 2 的指数
    r = t >> s
    for a in range(2, 200):
        x = pow(a, r, n)
        for j in range(s):
            g = gcd(x - 1, n)
            if 1 < g < n:
                return g, n // g
            x = x*x % n
```

## 易错点

1. **别把"能解密"当"必须分解"**：`pow(c,d,n)` 一行就够，分解是另一件事。
2. `ed−1` 若是 `λ = lcm(p−1,q−1)` 的倍数（d 对 λ 求的逆），同样能分解，只是命中率略低——多试几个 `a`。
3. `s = (t & -t).bit_length() - 1` 取的是 2 的指数，不是位数；`t` 为偶数时才对（`ed−1` 必偶）。
4. `φ` 泄露时若判别式不是完全平方，说明题面给的 φ 与 n 不匹配（可能给的是 λ），别硬套。
5. 分解只给出 `(p, q)` 的一个顺序，比对时用 `set((a,b)) == {p,q}`。

## 验证记录（2026-11-03，实测输出）

```text
== 路径一：只给 n 和 φ ==
恢复成功: True  p 位数 = 512
== 路径二：只给 n、e、d ==
恢复成功: True  命中基 a=2, 平方链 j=1, 用了 1 次尝试
== 对照：手上有 c 时其实不用分解 ==
pow(c,d,n) 直接解密: True
```

512 位 p/q（n 1024 位）下两条路径都是毫秒级；`a=2` 一次命中，j=1 说明 `v2(p−1) ≠ v2(q−1)` 只差一步。
