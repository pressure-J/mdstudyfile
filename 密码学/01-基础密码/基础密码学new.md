## 0. 先分清两个层次（这一步错了后面全白做）

拿到一串看不懂的东西，**第一件事不是解码，是判断它是"编码"还是"密码"**。

| | 编码（Encoding） | 密码（Cipher） |
|---|---|---|
| 本质 | 换一种表示，**不需要密钥** | 用密钥做变换 |
| 特征 | 字符集固定、长度关系可预测（如 base64 膨胀 4/3） | 字符集可能仍是 26 字母，但频率分布变了 |
| 判据 | 直接解一次看结果是否可读 | 算**重合指数 IC**：≈0.065 → 单表替换类；≈0.038 → 多表（维吉尼亚） |
| 处理 | 可反复套娃，一层层剥 | 需要密钥 / 统计 / 暴力 |

判别细节：`古典密码1.md` 第 1 节（分编码层和密码层）+ 第 2 节（IC 判别）。

**操作常识层**（怎么转码、怎么调函数）不在本篇 → `基础密码学.md`
（ASCII / hex / base64 基本用法 / 字节↔大整数 / 哈希函数 / XOR 及 pwn 用法）

## 古典密码体制与通用分析方法

### 凯撒 / 仿射 / 栅栏 → 暴力破解
24~26 种位移、a/b 两组密钥、栏数试 2~N。全是**有限空间枚举**，写个循环就完。
→ `古典密码1.md` §1–§4　｜　`crypto/01-凯撒爆破.py`、`02-仿射爆破.py`、`03-栅栏爆破.py`

### 维吉尼亚 / 单表替换 → 统计分析
密钥长度靠 IC / Kasiski 定，之后退化为多个凯撒；单表替换靠**频率 + 已知明文锚点**，退火是最后手段。
→ `古典密码1.md` §3、§5　｜　`crypto/05-维吉尼亚.py`、`16-单表替换-退火求解.py`

### 希尔（Hill）→ 矩阵求逆
密文按 n 个一组，密钥是 n×n 矩阵，解密 = 在 **Z₂₆ 或 Z₂₅₆ 上求逆矩阵**（要求 gcd(det, m)=1）。
希尔是古典的终点、现代分组密码的起点，所以**单独成篇**：
→ `古典的终点-希尔与分组思想.md`　｜　`crypto/29-希尔密码.py`

## 常用编码原理

### base 家族
16 / 32 / 64 / 85 / 91、URL-safe 变体、**换表 base64**。
判据：字符集 + 填充符 + 长度整除关系。
→ `编码体系.md` §1　｜　`misc/01-编码自动识别与解码.py`、`crypto/19-basemap.py`

### URL / HTML / Unicode 转义
`%XX`、`&#xXX;`、`\uXXXX`、`&amp;` 这类**结构性残留**，肉眼即可识别。
→ `编码体系.md` §2　｜　`misc/01`（含 url / html）

### 摩斯密码
点划 + 分隔符。难点不在对照表，在**分隔符被改写**（空格 / 斜杠 / 换行混用）。
→ `编码体系.md` §3　｜　`crypto/04-培根与摩斯.py`

### 冷门编码
键盘位移（QWERTY 错位）、T9、社会主义核心价值观、uuencode、JSFuck。
→ 独立篇 `冷门编码.md`（规则 + 代码 + 实测）　｜　`编码体系.md` §4（判据速览）
→ `misc/30-冷门编码三合一.py`（17 项自检）
