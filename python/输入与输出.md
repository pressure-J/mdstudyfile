# 输入与输出

## 一、直接 I/O（终端输入与输出）

### 1. print() —— 输出到终端

``````py
print("hello")                      # hello → 默认 end='\n' 自动换行
print("a", "b", "c")                # a b c → 多参数默认用空格拼接
print("a", "b", sep="-")            # a-b → sep 改分隔符
print("不换行", end="")              # end 改结尾（默认 \n）
print("a", "b", sep="", end="!\n")  # ab! → 拼接输出
print(1, 2, flush=True)             # 立即刷新缓冲区（交互/长时间循环时防止看不到输出）
``````

f-string 格式化（最常用）：

``````py
x = 255
name = "ctf"
print(f"flag{{{name}}}")            # flag{ctf} → 想输出 { } 就双写
print(f"{x}")                       # 255
print(f"{x:b}")                     # 11111111 → 二进制
print(f"{x:o}")                     # 377 → 八进制
print(f"{x:x}")                     # ff → 十六进制
print(f"{x:#x}")                    # 0xff → 带 0x 前缀
print(f"{x:08b}")                   # 11111111 → 宽度 8，不足补 0（掩码/位运算题）
print(f"{x:04d}")                   # 0255 → 宽度 4 补零
print(f"{3.14159:.2f}")             # 3.14 → 保留 2 位小数
print(f"{1234567:,}")               # 1,234,567 → 千分位
print(f"{0x41:c}")                  # A → 码点转字符
print(f"{name:>10}")                #        ctf → 右对齐宽 10（< 左对齐，^ 居中）
``````

`%` 老格式化和 `str.format()` 能看懂即可，新代码一律 f-string：

``````py
"%s=%d" % ("n", 1)                  # 'n=1'
"{}={}".format("n", 1)              # 'n=1'
"{:x}".format(255)                  # 'ff'
``````

### 2. input() —— 从终端读一行

`input()` 读**一行**，返回的永远是 **str**（连数字输入也是字符串）：

``````py
s = input()                 # 输入 hello → s = 'hello'
n = int(input())            # 输入 123 → n = 123（int）
a, b = input().split()      # 输入 1 2 → a='1', b='2'（默认按空白切）
a, b = map(int, input().split())        # 输入 3 5 → a=3, b=5
nums = list(map(int, input().split()))  # 输入 1 2 3 → [1, 2, 3]
s = input("请输入密码：")    # 参数是提示语，先打印再读
``````

### 3. CTF 交互题的多行读入模式

``````py
# 固定读 N 行
n = int(input())
lines = [input() for _ in range(n)]

# 未知行数，读到 EOF 为止（nc 交互/管道喂文件都适用）
import sys
for line in sys.stdin:          # 每行带结尾 \n
    line = line.rstrip("\n")    # 处理前先去掉换行符

# 或一次性全读进来按行切
data = sys.stdin.read()         # 全部内容一个 str
lines = data.splitlines()       # 按行切好且不带 \n

# 交互脚本里循环读（EOF 时 input() 抛异常，要接住）
while True:
    try:
        line = input()
    except EOFError:
        break
    print(line)
``````

> 和外部进程交互（subprocess/pty 读写子进程的输入输出）另见 `Python-终端交互subprocess与pty.md`。

### 4. 常见坑

- `input()` 返回 str：`input() + 1` 直接 TypeError，先 `int()` / `float()`。
- `input().split()` 切完还是字符串列表，算术前要 `map(int, ...)`。
- 想输入空格再切：`split()` 不带参数能吃掉多个连续空格，`split(" ")` 会切出空串。
- `print(a + b)` 当 a、b 是 str 时是拼接不是加法（`'1' + '2'` = `'12'`）。
- 循环里大量 print 不刷新时加 `flush=True`。
- `f"{name}"` 里想输出字面 `{` 必须写 `{{`。

## 二、文件 I/O

### 1. open() 与打开模式

``````py
f = open(path, mode, encoding="utf-8")
``````

| 模式 | 含义 | 文件不存在 | 文件已存在 |
|---|---|---|---|
| `r` | 只读（默认） | 报错 | 从头读 |
| `w` | 只写 | 新建 | **清空整个文件** |
| `a` | 追加 | 新建 | 从末尾接着写 |
| `x` | 新建写入 | 新建 | 报错（防覆盖） |
| `b` | 二进制（和上面组合：`rb`/`wb`/`ab`） | - | - |
| `+` | 读写（`r+`/`w+`/`a+`） | - | - |

- 文本模式默认还带 `t`（`rt`），读写的是 **str**；`b` 模式读写的是 **bytes**。
- **encoding 必须显式写**：Windows 默认 GBK，读 UTF-8 文件不加会 `UnicodeDecodeError`，写出的文件别人打开是乱码。
- str ↔ bytes 的编解码细节另见 `Python3-str与bytes编码.md`。

### 2. with 语句（推荐写法）

``````py
# with 结束自动 f.close()，即使中间抛异常也会关闭
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()
# 出了 with 块文件已关闭
``````

不用 with 就必须手动 close，忘 close 会导致文件一直被占用、数据没写盘：

``````py
f = open("data.txt", "r", encoding="utf-8")
try:
    text = f.read()
finally:
    f.close()
``````

### 3. 读文件的四种方式

文件内容 `第一行\n第二行\n第三行`：

``````py
f.read()        # '第一行\n第二行\n第三行' → 整个文件一个 str（小文件用）
f.read(5)       # 只读 5 个字符
f.readline()    # '第一行\n' → 每次读一行（带 \n），读完返回 ''
f.readlines()   # ['第一行\n', '第二行\n', '第三行\n'] → 所有行组成的列表

# 最推荐：直接迭代文件对象，一行一行读，大文件也不爆内存
for line in f:
    print(line.rstrip("\n"))    # rstrip 去掉行尾换行
``````

大文件别用 `read()`/`readlines()` 一次性全读（几百 MB 直接爆内存），用 `for line in f` 逐行处理。

### 4. 写文件

``````py
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("hello\n")          # 写 str，\n 不会自动补
    f.write("world")
    f.writelines(["a\n", "b\n"])  # 接一个可迭代对象逐个写（不会自动加 \n）

with open("log.txt", "a", encoding="utf-8") as f:
    f.write("追加一行\n")         # a 模式不清空，接着末尾写

# 二进制写（bytes）——写图片、密文、构造的文件
with open("out.bin", "wb") as f:
    f.write(b"\x00\x01\x02")
    f.write(bytes.fromhex("deadbeef"))
``````

### 5. 二进制读与文件指针

``````py
with open("out.bin", "rb") as f:
    head = f.read(4)        # 前 4 个字节（文件头/magic number 检查常用）
    rest = f.read()         # 接着读到末尾
    f.seek(0)               # 指针移回开头，之后 read() 从头再读
    again = f.read()
    f.tell()                # 当前指针位置（字节偏移）
``````

- 文本模式下 seek 只能用 `f.seek(0)` 回开头等安全用法（按字符算，随机偏移会报错）；需要随机读就开 `rb`。
- `r+` 打开后写入是**覆盖**当前位置的内容，不是插入；要插入只能读出→改→重写整个文件。

### 6. CTF 场景常用片段

``````py
# ① 读出题附件里的 n / e（配合正则）——详见 Python-文本文件读取正则提取.md
import re
text = open("1.txt", encoding="utf-8").read()
ns = [int(x) for x in re.findall(r"n = (\d+)", text)]

# ② json 读写（读题目给的 json、写提交结果）
import json
data = json.load(open("data.json", encoding="utf-8"))       # 读：文件 → dict
json.dump({"flag": "xxx"}, open("res.json", "w", encoding="utf-8"))  # 写

# ③ csv 读写
import csv
with open("t.csv", newline="", encoding="utf-8") as f:
    rows = list(csv.reader(f))          # 每行一个列表
with open("t.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)

# ④ pickle（读 python 序列化的附件对象）
import pickle
obj = pickle.load(open("data.pkl", "rb"))   # 必须 rb；pickle 反序列化会执行代码，别读不可信文件

# ⑤ 路径不存在时新建目录再写
import os
os.makedirs("out", exist_ok=True)
``````

### 7. 常见坑

- `w` 一打开就清空原文件——想保留就先读出来或用 `a`。
- 不写 `encoding="utf-8"`：Windows 下读 UTF-8 文件报 `UnicodeDecodeError`，解不开加 `errors="ignore"` 兜底（CTF 文件常混入脏字节）。
- 文本模式读出来每行带 `\n`，比较/拼接前 `line.strip()` 或 `rstrip("\n")`。
- `b` 模式下 `write("str")` 报错，必须 bytes（`s.encode()` 转换）；反之文本模式不能写 bytes。
- 相对路径是相对**运行时的工作目录**，不是脚本所在目录——找不到文件时先确认 cwd，或直接写绝对路径（Windows 下用 `r"C:\Users\..."` 原始字符串防 `\` 转义）。
- 忘记 close / 不用 with：写的内容可能还停在缓冲区没落盘。
