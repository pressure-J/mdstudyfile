# RSA — p+1 光滑（Williams p+1）

## 题型识别（一眼看出）

- 生成脚本里 p 由**小素数连乘减一**构造：`p = 2*3*5*7*... - 1`、`p = factorial(k) - 1`、`p = prod(small_primes) - 1`；
- 题面提示 "p+1 smooth"，或 p−1 攻击（Pollard p−1）跑不动但 n 又明显不是普通题。

**与 p−1 攻击的关系**：`p−1` 光滑 → Pollard p−1 命中；`p+1` 光滑 → 这个。两个是镜像，出题人常只堵一边。

## 原理

Lucas 序列 `V_k(P, 1)`（`V_0=2, V_1=P`）满足 `V_{p+1}(P) ≡ 2 (mod p)`，**前提是 `(P²−4 | p) = −1`**（即 `x²−Px+1` 在 F_p 上不可约）。

于是取 `M = lcm(1..B)`，若 `p+1 | M`，则

$$
\gcd\bigl(V_M(P) - 2,\; n\bigr) = p
$$

`V` 序列可以复合：`V_a(V_b(P)) = V_{ab}(P)`（Q=1 时不变），所以**逐级把每个素数幂作用到 P 上**，不要一次算 `V_{lcm}`（那是几万位的指数，会慢死）。

## 代码（核心）

```python
def lucas_v(k, P, n):            # 迭代二进制法，O(log k) 次模乘
    v0, v1 = P % n, (P*P - 2) % n            # V_1, V_2
    for bit in bin(k)[3:]:
        v2m  = (v0*v0 - 2) % n
        v2m1 = (v0*v1 - P) % n
        v2m2 = (v1*v1 - 2) % n
        v0, v1 = (v2m, v2m1) if bit == '0' else (v2m1, v2m2)
    return v0

def williams(n, B, bases):
    for P in bases:              # 关键：基里必须有随机大数
        x = P % n
        for pk in prime_powers(B):        # 升序素数幂，连乘即 lcm(1..B)
            x = lucas_v(pk, x, n)
        g = gcd(x - 2, n)
        if 1 < g < n:
            return g, n // g, P
```

## 易错点（第一条是本次实测踩到的真坑）

1. **基 P 不能只取小素数。** 命中要求 `(P²−4 | p) = −1`。而"p 由小素数连乘 −1"的构造天然造成 `p ≡ −1 (mod 每个小素数)`，此时用 `P = 2,3,5,7,…` 去算 Jacobi 符号会**系统性全是 +1**：实测 21 个小基全是 +1，B 加到 10 万也不命中。**必须补随机大基**（`rnd.randrange(2, n)`），随机基与 p 无关，各占一半。
2. **B 要覆盖的是 p+1 的「素幂」，不是最大素因子。** p+1 含 `2^13` 时 `B=1000` 的 `lcm` 只到 `2^9`，`p+1 ∤ M`，必失败；`B=10000` 才够。构造或调参时按 `max(素幂)` 想，不要按最大素数想。
3. 一次算 `V_lcm` 会因指数位数过大而跑不动，必须逐级复合。
4. `gcd` 结果等于 n 表示这个基两边同时命中（P 对 q 也是 −1），换基；等于 1 就是没命中。
5. Williams 只对 `p+1` 光滑的因子有效；若 p−1 光滑，先试 Pollard p−1（更快）。
