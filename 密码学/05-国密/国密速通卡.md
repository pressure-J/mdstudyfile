# 国密速通卡（15 分钟版）

> **先读这篇。** 算法内部（轮函数、S 盒、密钥扩展）**不用懂**。
> CTF 国密题的攻击点几乎全在**用法层**（模式、随机数、结构），不在算法本身。
> 需要抠内部细节时再翻三篇专篇。

## 1. 最小认知：三个算法各记一句

| 算法 | 一句话 | 类比 |
|---|---|---|
| **SM4** | 对称加密，给一把钥匙加密数据 | 就是国版 AES |
| **SM3** | 算指纹，输入任意长度输出 256 位 | 就是国版 SHA-256 |
| **SM2** | 公钥加密/签名，一把公开一把私藏 | 就是国版 ECDSA |

**为什么不用懂内部**：这些算法本身都是安全的。出题人**破不了算法**，只能利用：
- 用错了模式（SM4）
- 随机数复用了（SM2）
- 结构天生的弱点（SM3）

## 2. 三个攻击（占 CTF 国密题 90%）

### 攻击 1：SM4 密钥流重用 —— 最高频

**看到什么就用**：同一段密钥/IV 加密了两段数据，且给了一组已知明文。

**原理两行**：
```text
密文 = 明文 XOR 密钥流
同一 IV → 同一密钥流 → 两式相减消掉密钥流
```

**公式**：`P_b = C_a XOR C_b XOR P_a`

**跑**：`py SM4-工作模式攻击-solve.py`（看 `[考点3]`）

### 攻击 2：SM2 随机数 k 重用 —— 直接出私钥

**看到什么就用**：给了两组 SM2 签名，题面提示"随机数""同一 k""设备缺陷"。

**原理两行**：
```text
签名用了同一个随机数 k → 两组签名可联立 → 解出私钥 d
```

**公式**：`d = t / (1 - t)`，其中 `t = (s1-s2)/(r2-r1) mod n`

> ⚠️ **别照抄 ECDSA 的公式**（`k=(e1-e2)/(s1-s2)`）——SM2 签名方程不同，那样算出来是垃圾值。脚本末段专门跑了这个反例。

**跑**：`py SM2-随机数k重用攻击-solve.py`

### 攻击 3：SM3 长度扩展

**看到什么就用**：`摘要 = SM3(密钥 || 数据)`，要求你伪造一条合法数据。

**原理两行**：
```text
摘要 = 内部状态。拿到摘要 = 拿到状态
可以从这个状态继续往后压缩，凭空拼出合法摘要，不需要知道密钥
```

**坑**：密钥长度不知道 → 爆破 0..63，因为填充要按原长度算。

**跑**：`py SM3-长度扩展攻击-solve.py`

## 3. 三步判断法（拿到题先做这个）

```text
第一步：改明文 1 个字节，密文只变对应 1 个字节？
        → 是：流式模式（OFB/CTR）→ 查 IV 是否复用
        → 否（整块雪崩 16 字节）：ECB 或 CBC
第二步：题面出现"随机数/签名/私钥"？ → SM2 → 查两组签名的 x1 是否相同
第三步：出现"哈希/摘要/密钥前置"？  → SM3 → 查是否 MD 结构的长度扩展
```

**第一步的判据实测**（改明文第 4 字节 1 bit）：

| 模式 | 密文变化字节数 |
|---|---|
| ECB 单块 | 16/16（整块雪崩） |
| CBC 单块 | 16/16（整块雪崩） |
| **OFB** | **1/16（只有对应字节变）** |

> 别用"密文长度 == 明文长度"当判据——无填充的 ECB 也是等长，会误判。要看清的是**扩散范围**。

## 4. 抄这四行命令就够用

```bash
# SM3 算指纹
echo -n abc | openssl dgst -sm3

# SM4 加解密（KEY/IV 都是 32 位十六进制）
openssl enc -sm4-cbc -K <32位hex> -iv <32位hex> -in p.txt -out c.bin
openssl enc -d -sm4-cbc -K <32位hex> -iv <32位hex> -in c.bin

# SM2 生成密钥对
openssl genpkey -algorithm ec -pkeyopt ec_paramgen_curve:SM2 -out k.pem
```

Python 里用 `gmssl` 库（本机已装）：`from gmssl import sm2, sm3, sm4`

## 5. 什么时候才需要翻专篇

| 情况 | 翻哪篇 |
|---|---|
| 题目给了非标准曲线参数 a/b/G | SM2 §3.3（无效曲线/小阶子群） |
| 要伪造 SM3 碰撞 | SM3 §3.3（结论：全轮不可行，直接放弃） |
| 有解密报错反馈（padding oracle） | SM4 §3.4 |
| 纯理论题/面试问"SM4 为什么安全" | SM4 §2.2（S 盒与扩散） |

**其余情况都不需要读原理。**
