## 1. 整除与欧几里得

### 1.1 gcd（欧几里得算法）

原理：`gcd(a,b) = gcd(b, a mod b)`，反复直到余数为 0。

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return abs(a)
```

**手算示例**：`gcd(1071, 462)`

```
1071 ÷ 462 = 2 余 147   → gcd(462, 147)
 462 ÷ 147 = 3 余  21   → gcd(147, 21)
 147 ÷  21 = 7 余   0   → gcd = 21
```

> 实测 `gcd(1071,462) = 21` ✅

### 1.2 扩展欧几里得（求 `ax + by = gcd(a,b)`）

不只是求 gcd，还顺带解出系数 `x, y`。**这是求模逆的正统方法。**

```python
def gcdext(a, b):
    """返回 (g, x, y) 使得 a*x + b*y = g = gcd(a,b)"""
    x0, x1, y0, y1 = 1, 0, 0, 1
    while b:
        q = a // b
        a, b = b, a - q * b
        x0, x1 = x1, x0 - q * x1
        y0, y1 = y1, y0 - q * y1
    return a, x0, y0
```

> 实测 `gcdext(240, 46) = (2, -9, 47)`，校验 `240×(-9) + 46×47 = 2` ✅

### 1.3 三种求模逆的方法（都要会，互为校验）

求 `a·x ≡ 1 (mod m)`，即 `a·x + m·y = 1`。

| 方法 | 条件 | 适用 |
|---|---|---|
| 扩展欧几里得 | `gcd(a,m)=1` | **通用**，m 不一定是素数 |
| 费马小定理 | m 必须是**素数** | `a^(p-2) mod p`，RSA 里常用 |
| `pow(a,-1,m)` | Python 3.8+ | 最省事，内部用扩展欧几里得 |

```python
def inv(a, m):
    g, x, _ = gcdext(a % m, m)
    if g != 1:
        raise ValueError(f"gcd={g}，模 {m} 下不可逆")
    return x % m
```

> 实测：`3⁻¹ mod 13` → 扩展欧几里得 `9`、`pow(3,-1,13)` `9`、费马 `pow(3,11,13)` `9` —— 三法一致，校验 `3×9 mod 13 = 1` ✅

**什么时候不可逆**：`gcd(a,m) ≠ 1`。这是 RSA 里 `e` 必须与 `φ(n)` 互素的原因。

## 2. 模运算：规则与技巧

### 2.1 基本同余规则（原笔记整理）

若 `a ≡ b (mod n)`，则：

| 运算 | 规则 |
|---|---|
| 加法 | `a + c ≡ b + c (mod n)` |
| 减法 | `a − c ≡ b − c (mod n)` |
| 乘法 | `a × c ≡ b × c (mod n)` |
| 交叉相乘 | 若 `a≡b`、`c≡d`，则 `ac ≡ bd (mod n)` |
| 幂 | `a^k ≡ b^k (mod n)` |
| **除法** | ⚠️ **不成立**，必须乘逆元，见 §2.3 |

### 2.2 四条省时间的技巧（做题真正用到的）

#### 技巧 1：边算边取模

大数不要算完再模，每一步都模——数值永远压在小范围内。

```python
r = 1
for x in data:
    r = (r * x) % m          # ✅ 每步取模
    # r *= x                  # ❌ 会膨胀成几万位，慢到跑不完
```

#### 技巧 2：快速幂（必须条件反射）

```python
pow(a, e, m)
```

`pow(2, 100, 10**9+7)` = `976371285`，瞬间出结果。
**手写版**（理解原理用，实际永远用内置）：

```python
def qpow(a, e, m):
    r = 1; a %= m
    while e:
        if e & 1: r = r * a % m
        a = a * a % m
        e >>= 1
    return r
```

#### 技巧 3：欧拉/费马降幂（指数特别大时）

`gcd(a,m)=1` 时：`a^e mod m = a^(e mod φ(m)) mod m`

```python
e_reduced = e % sympy.totient(m)
pow(a, e_reduced, m)
```

⚠️ 前提是 `gcd(a,m)=1`。不互素时要用"扩展欧拉定理"分情况讨论，不能直接降。

#### 技巧 4：负数取模的语言差异（**高频坑**）

| 语言 | `-7 % 3` | 规则 |
|---|---|---|
| **Python** | **2** | 结果符号跟**除数**走 |
| C / C++ / Java | -1 | 结果符号跟**被除数**走 |

CTF 题面常写"取模后为正"，就是提醒你这点。Python 里 `x % m` 天然落在 `[0, m)`，**这点 Python 反而省事**。

### 2.3 除法 = 乘逆元（最容易错的一条）

```
a/b mod m  ≠  (a mod m) / (b mod m)
a/b mod m  =  a · b⁻¹ mod m
```

**前提**：`gcd(b, m) = 1`。

例：`7/3 mod 13` → `7 × 3⁻¹ = 7 × 9 = 63 ≡ 11 (mod 13)`。
验算：`11 × 3 = 33 ≡ 7 (mod 13)` ✅

### 2.4 几条能加速手算的"规律"

| 规律 | 用途 |
|---|---|
| `a` 为奇数 → `a² ≡ 1 (mod 8)` | 快速排除/构造 |
| `p ≡ 1 (mod 4)` → `-1` 是二次剩余 | 判定模平方根是否存在 |
| `p ≡ 3 (mod 4)` → `x = a^((p+1)/4)` 直接得模平方根 | 省掉 Tonelli-Shanks |
| 模 9：各位数字和 | 手算大数余数 |
| 模 11：奇数位和 − 偶数位和 | 同上 |
| `a^φ(m) ≡ 1` | 降幂、求逆 |
| 幂的循环节必整除 `φ(m)` | 判断周期 |

### 2.5 Python 三个必知行为

1. `%` 结果恒非负（除数正时）；
2. `pow(a, e, m)` 三参数版自带快速幂 + 自动取模，**大数场景必须用它**；
3. `pow(a, -1, m)` 求模逆，`a` 不可逆时抛 `ValueError`。

## 3. 费马小定理

### 3.1 定理

若 `p` 为素数且 `p ∤ a`，则

$$a^{p-1} \equiv 1 \pmod{p}$$

### 3.2 证明思路（原笔记保留）

考虑集合 `{a, 2a, 3a, …, (p−1)a}`。模 p 下，它们恰好是 `{1, 2, …, p−1}` 的一个**排列**（因为 a 与 p 互素，两两不同余）。

于是：

$$a \cdot 2a \cdots (p-1)a \equiv 1 \cdot 2 \cdots (p-1) \pmod p$$
$$a^{p-1}(p-1)! \equiv (p-1)! \pmod p$$

`(p−1)!` 与 p 互素，两边约去即得 `a^(p−1) ≡ 1`。

### 3.3 三个用途

| 用途 | 写法 |
|---|---|
| 求逆元 | `a⁻¹ ≡ a^(p−2) (mod p)` |
| 降幂 | `a^e ≡ a^(e mod (p−1))` |
| **判定素数**（单向） | `a^(p−1) ≡ 1` 不成立 → **一定是合数**；成立 → 只说明"可能是素数"（`Carmichael 数`会骗人） |

> 实测：`3*d ≡ 1 (mod 13)` → `d = 3^11 mod 13 = 9`，校验 `3×9 = 27 ≡ 1` ✅

## 4. 欧拉定理与欧拉函数

### 4.1 定理（费马小定理的推广）

若 `gcd(a, n) = 1`，则

$$a^{\varphi(n)} \equiv 1 \pmod{n}$$

`φ(n)` 是不超过 n 且与 n 互质的正整数个数。

### 4.2 φ(n) 怎么算

| 情形 | 公式 |
|---|---|
| n 为素数 p | `φ(p) = p − 1` |
| n = p·q（p,q 素数） | `φ(n) = (p−1)(q−1)` ← **RSA 核心** |
| n = p^k | `φ(n) = p^k − p^(k−1)` |
| 一般 n | `φ(n) = n · ∏(1 − 1/p_i)`（p_i 是 n 的不同素因子） |

```python
import sympy
sympy.totient(100)      # 40
sympy.factorint(100)    # {2: 2, 5: 2}  → 100*(1-1/2)*(1-1/5) = 40
```

### 4.3 降幂的正确姿势

```
gcd(a, m) = 1  →  a^e ≡ a^(e mod φ(m)) (mod m)
gcd(a, m) ≠ 1  →  不能直接降，需用扩展欧拉定理分情况
```

## 5. 二次剩余

### 5.1 定义

存在整数 x 使 `x² ≡ a (mod m)`，则 a 是模 m 的**二次剩余**（QR），否则是**二次非剩余**（QNR）。

**示例（模 7）**：

| x | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| x² mod 7 | 1 | 4 | 2 | 2 | 4 | 1 |

→ 二次剩余 `{1, 2, 4}`，非剩余 `{3, 5, 6}`。
**规律**：模素数 p 恰好有 `(p−1)/2` 个 QR，且 `x` 与 `p−x` 的平方相同（成对出现）。

### 5.2 勒让德符号

$$\left(\frac{a}{p}\right)=\begin{cases}0 & p \mid a\\ 1 & a \text{ 是 QR}\\ -1 & a \text{ 是 QNR}\end{cases}$$

性质：

- `(ab/p) = (a/p)(b/p)` — 完全积性
- `(1/p) = 1`
- `(-1/p) = (-1)^((p−1)/2)`

示例：`(2/7)=1`、`(3/7)=−1`、`(14/7)=0`。

### 5.3 欧拉准则（计算它的方法）

$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod{p}$$

```python
def is_qr(a, p):
    return pow(a, (p - 1) // 2, p) == 1
```

### 5.4 −1 什么时候是二次剩余

由上：`(-1/p) = (-1)^((p−1)/2)`

| p 的形式 | 结论 |
|---|---|
| `p ≡ 1 (mod 4)` | **−1 是**二次剩余 |
| `p ≡ 3 (mod 4)` | **−1 不是** |

> 这条直接决定 Rabin 加密能否解、以及模平方根有没有解。

### 5.5 模平方根

给定奇素数 p 与 QR `a`，求 `x² ≡ a (mod p)`：

| 情况 | 方法 |
|---|---|
| `p ≡ 3 (mod 4)` | `x = a^((p+1)/4) mod p`（一步） |
| `p ≡ 1 (mod 4)` | **Tonelli-Shanks** |

```python
from sympy.ntheory.residue_ntheory import sqrt_mod
sqrt_mod(a, p)          # 返回一个根；另一个是 p - 它
```

> 注意：开出来的永远是**两个根**。Rabin 题有两个/四个候选解，靠**校验码或明文结构**筛唯一。

## 6. 中国剩余定理（CRT）

### 6.1 定理

若 `m₁, m₂, …, m_k` **两两互质**，则方程组

$$x \equiv a_1 \pmod{m_1},\ \dots,\ x \equiv a_k \pmod{m_k}$$

在模 `M = ∏m_i` 下有**唯一解**。

### 6.2 构造法（原笔记修正版）

令 `M = ∏m_i`，`M_i = M/m_i`，`t_i = M_i⁻¹ mod m_i`，则

$$x = \sum a_i M_i t_i \bmod M$$

```python
from math import prod

def crt(a_list, m_list):
    """要求 m_list 两两互质"""
    for i in range(len(m_list)):
        for j in range(i + 1, len(m_list)):
            if gcd(m_list[i], m_list[j]) != 1:
                raise ValueError(f"模数 {m_list[i]} 与 {m_list[j]} 不互质")
    M = prod(m_list)
    x = 0
    for a_i, m_i in zip(a_list, m_list):
        M_i = M // m_i
        x = (x + a_i * M_i * inv(M_i, m_i)) % M
    return x
```

> 实测：`x ≡ 2(3), 3(5), 2(7)` → `x = 23`，校验 `23%3, 23%5, 23%7 = [2,3,2]` ✅

### 6.3 模数不互质怎么办

先逐对合并：`x ≡ a₁(m₁), x ≡ a₂(m₂)` 有解 ⇔ `a₁ ≡ a₂ (mod gcd(m₁,m₂))`。
有解时解模 `lcm(m₁,m₂)` 唯一，可逐条合并下去（不用两两互质）。

### 6.4 在 RSA 里的用法

**低指数广播攻击**：同一明文 `m`、`e=3`，三组不同 `n` 加密 → 得到 `c₁,c₂,c₃`。
若 `m³ < n₁n₂n₃`，用 CRT 合并出 `m³`，再开三次方即得 `m`（**不需要分解任何 n**）。
详见 `../02-公钥密码/RSA低指数广播攻击.md`。

## 7. 有限域（新增）

> PPT 模块 1 点名的"有限域基础"。CTF 里出现频率低于模运算，但 **AES/SM4 的 S 盒、GF(2ⁿ) 上的 ECC、Reed-Solomon** 都建在这上面。

### 7.1 什么是域，为什么密码学要用它

**域** = 一个集合 + 两种运算（加、乘），满足：封闭、结合、交换、有单位元、**每个非零元素都有逆元**、乘法对加法分配。

**关键就是"每个非零元素都有逆元"** —— 没有逆元就没法做"除法"，加密解密、解方程组全都无从谈起。

有限域（Galois Field）= 元素个数有限的域，记 `GF(q)`，**q 必为素数幂** `p^n`。

### 7.2 GF(p)：素域

`p` 为素数时，`{0, 1, …, p−1}` 配上"模 p 加法/乘法"就构成一个域。

> 实测（GF(17)）：`5⁻¹ = 7`，校验 `5×7 = 35 ≡ 1 (mod 17)` ✅

### 7.3 为什么模数必须是素数

合数会引入**零因子**：`m = 6` 时 `2 × 3 = 6 ≡ 0 (mod 6)`，但 2 和 3 都非零。

零因子没有逆元（若 2 有逆 `2⁻¹`，则 `3 = 2⁻¹·2·3 ≡ 0`，矛盾）。**所以 `Z₆` 只是环，不是域。**

→ 这就是为什么 **RSA 的模 `n = pq` 不是域**，而 ECC 的坐标域 `GF(p)` 必须是素数域。

### 7.4 GF(2ⁿ)：扩域

`GF(2)` 只有 `{0,1}`，太小。要得到 `2ⁿ` 个元素，用**多项式**：

> GF(2ⁿ) 的元素 = 次数 < n 的二进制多项式
> 加法 = **按位异或**（没有进位，系数模 2）
> 乘法 = 多项式相乘，再对**不可约多项式**取模

**GF(2⁸) 实例**：元素就是一个字节，不可约多项式取 AES 的 `x⁸+x⁴+x³+x+1` = `0x11B`。

```python
def gf_mul(a, b, poly=0x11B):
    """GF(2^8) 乘法：8 轮移位 + 条件约简"""
    r = 0
    for _ in range(8):
        if b & 1:
            r ^= a
        b >>= 1
        hi = a & 0x80
        a = (a << 1) & 0xFF
        if hi:
            a ^= (poly & 0xFF)      # 溢出时减掉不可约多项式
    return r

def gf_inv(a):
    """GF(2^8) 求逆：a^(2^8-2) = a^254"""
    if a == 0:
        raise ZeroDivisionError
    r, e = 1, 254
    while e:
        if e & 1:
            r = gf_mul(r, a)
        a = gf_mul(a, a)
        e >>= 1
    return r
```

> 实测：
> - `0x57 × 0x83 = 0xC1`（AES 文档里的经典例子）✅
> - `inv(0x02) = 0x8D`，校验 `0x02 × 0x8D = 0x01` ✅
> - `inv(0x53) = 0xCA` ✅ ← **这正是 AES S 盒的中间值**

### 7.5 GF(2⁸) 与 AES 的 S 盒

AES 的 S 盒构造分两步：

```
S(x) = 仿射变换( GF(2⁸) 上的乘法逆元 x⁻¹ )
       其中 x⁻¹ 按 0x11B 取模，x=0 时约定 x⁻¹=0
```

所以：**S 盒的非线性，全部来自有限域求逆**。
`inv(0x53) = 0xCA` 就是最常用的自检点（`0xCA` 再经仿射变换得到 S 盒里的 `0xED`）。

> 这一条把 PPT 模块 7 的"密码组件安全强度分析（如 S 盒特性）"接上了：
> 讨论 S 盒的**差分均匀度 / 线性度 / 代数次数**，本质都在讨论"这个有限域构造够不够非线性"。

### 7.6 有限域上的离散对数

`GF(p)` 上：给定 `g` 和 `g^k mod p`，求 `k` → 离散对数问题（DH/ECC 的安全性基础）。
`GF(2ⁿ)` 上同理，但存在**亚指数算法**（index calculus），所以相同位数下 `GF(2ⁿ)` 比素域弱——这也是现代 ECC 多用素域的原因之一。

### 7.7 和 SM4 的关系（一句提醒）

SM4 的 S 盒同样由仿射变换与有限域运算复合构造，但参数与 AES 不同。
**考题若问"S 盒特性"，先答：非线性来源、差分均匀度、线性逼近、代数次数；不要凭印象断言两套 S 盒的等价关系**——以 GB/T 32907 附录为准。

## 9. 易错点

- **把除法当普通除法**：模下必须乘逆元，且要先确认逆存在。
- **`pow(a,e,m)` 写成 `a**e % m`**：`a**e` 会先算出一个天文数字，慢到卡死甚至 OOM。
- **`pow(a,-1,m)` 不可逆时抛异常**：`gcd(a,m)≠1` 就是没有逆，别去 hack。
- **费马小定理反推素数**：`a^(p−1)≡1` 成立**不能**证明 p 是素数（Carmichael 数）。必须用 Miller-Rabin。
- **降幂漏条件**：`a^e ≡ a^(e mod φ(m))` 要求 `gcd(a,m)=1`。
- **CRT 模数不互质仍套公式**：会算出错解，必须先合并或检查相容性。
- **二次剩余只开出一个根**：开方恒有两解，Rabin 题必须靠校验码/结构筛。
- **负数取模跨语言**：Python 得正、C 得负，跨语言对拍时必查。
- **`φ(p^k)` 漏掉减号**：是 `p^k − p^(k−1)`，不是 `p^k − 1`。
