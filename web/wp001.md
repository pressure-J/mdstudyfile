# wp001
## 基于线性关系的模运算攻击
题目描述
 N=p*q
 c1=pow(2*p+3*q,e1,N)
 c2=pow(5*p+7*q,e2,N) 
已知c1,c2,e1,e2,N求p,q
思路
题目中显示了c1,c2之间有一定线性关系，可以尝试消去p或者q构造一个数与N求公因子
解题代码
``````py
# 将c1,c2升幂，算出q1和q2
q1 = pow(c1, e2, n) 
q2 = pow(c2, e1, n)
# 构造线性组合，消去p，算出d且d%q==0
term1 = pow(5, e1 * e2, n) * q1 % n
term2 = pow(2, e1 * e2, n) * q2 % n
d = (term1 - term2) % n
# 计算GCD得到q
q = gcd(d, n)
p = n // q
# 验证结果
print("p =", p)
print("q =", q)
print("验证 p * q == n:", p * q == n)
``````
