## 二、解释器索引：`D:\解释器`

用 **NTFS 目录联接（Junction）** 指向真身，**不占空间、不搬文件**，只是"统一入口"（共 10 个联接，占 16K）。

```powershell
D:\解释器\python\3.12.6-classic\python.exe -V      # → Python 3.12.6
D:\解释器\php\7.3.4-nts\php.exe -v                 # → PHP 7.3.4
D:\解释器\node\26.7.0-hermes\node.exe -v
```

| 分类 | 目录 | 版本 | 真实位置 |
|---|---|---|---|
| python | `3.12.6-classic` | 3.12.6 | `D:\徐利杰` ← **`py` 启动器默认** |
| python | `3.14.7-hermes` | 3.14.7 | `%LOCALAPPDATA%\hermes\tools\python-3.14.7...` |
| node | `26.7.0-hermes` | v26.7.0 | `%LOCALAPPDATA%\hermes\tools\node-26.7.0-win32-x64` |
| php | `5.6.9-nts` | 5.6.9 | `D:\phpstudy_pro\Extensions\php\php5.6.9nts` |

## 三、SageMath 9.3（密码学专用，独立安装）

做密码题调用这个，**不在解释器目录里**（自带 cygwin 运行时，独立安装）：

```powershell
cd "C:\Users\徐利杰\AppData\Local\SageMath 9.3"
.\runtime\bin\bash.exe --login -c "/opt/sagemath-9.3/sage -c 'print(factor(2^64-1))'"
```

- 版本 9.3（2021-05-09），约 4.48 GB
- 含 `ecm.exe`（椭圆曲线分解法）→ `...\opt\sagemath-9.3\local\bin\ecm.exe`
- 交互式：双击桌面「SageMath 9.3 Shell」

## 六、杀软白名单（重要）

三家**各有各的信任区，互不相通**，加白要分别加：

| 杀软 | 加白位置 | 状态 |
|---|---|---|
| Windows Defender | 排除项（`Add-MpPreference -ExclusionPath`） | `D:\网络安全工具` 等已加 |
| 火绒 | 信任区 → 添加文件夹 | 已加 |
| 联想电脑管家 | 设置 → 病毒查杀 → 信任区 | ⚠️ 待确认 |

