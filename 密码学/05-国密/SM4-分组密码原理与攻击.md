# SM4 分组密码：原理与攻击

国密**分组对称密码**，标准号 **GM/T 0002**（旧称 SMS4，GB/T 32907）。分组 128 bit、密钥 128 bit，**32 轮**。设计目标是替代 AES，抗差分/线性分析强度与 AES 同级。

> 姊妹篇：[SM3-杂凑算法原理与攻击](SM3-杂凑算法原理与攻击.md) · [SM2-椭圆曲线公钥算法原理与攻击](SM2-椭圆曲线公钥算法原理与攻击.md)

## 2. 算法原理

### 2.1 整体结构：32 轮非平衡 Feistel

明文 128 bit 按**大端**拆成 4 个 32 位字 $X_0 X_1 X_2 X_3$，做 32 轮：

$$X_{i+4} = X_i \oplus T(X_{i+1} \oplus X_{i+2} \oplus X_{i+3} \oplus rk_i), \quad i = 0,1,\dots,31$$

输出为**逆序**的**最后四个字**：

$$Y = (X_{35},\ X_{34},\ X_{33},\ X_{32})$$

注意：每轮只有**一个新字**参与 S 盒，$X_i$ 是被"挤掉"的那个——这就是"非平衡 Feistel"的含义，32 轮后 4 个字都换过数轮。

**为什么加密轮密钥逆序就是解密**：Feistel 结构每轮可逆，且加解密用同一套电路。实测（本机 gmssl）：

> 加密 sk[0] = 0xf12186f9
> 解密 sk[0] = 0x9124a012  (= 加密 sk[31])
> 解密轮密钥恰为加密轮密钥的逆序: True ✅

### 2.2 轮函数 T = 非线性 τ + 线性 L

$$T(x) = L\big(\tau(x)\big)$$

**非线性层 τ**：把 32 位按字节过 S 盒
$$\tau(x) = S(b_0) \| S(b_1) \| S(b_2) \| S(b_3)$$

**线性层 L**（循环左移 ⊕）：
$$L(B) = B \oplus (B \lll 2) \oplus (B \lll 10) \oplus (B \lll 18) \oplus (B \lll 24)$$

实测代码确认（gmssl 的 `_sm4_l_t` 就是这四个移位量）：

> c = bb ^ rotl(bb, 2) ^ rotl(bb, 10) ^ rotl(bb, 18) ^ rotl(bb, 24)

**S 盒**：8 bit 输入 → 8 bit 输出，构造为**有限域 $GF(2^8)$ 上求逆 + 仿射变换**（与 AES 同思路，但多项式与仿射矩阵不同）。首 8 项实测：`d6 90 e9 fe cc e1 3d b7`。

> S 盒是 SM4 唯一非线性来源，差分/线性分析都围绕它做。它满足差分均匀度 4、线性偏差有界，这是安全性的基石。

### 2.3 密钥扩展

主密钥 $MK = MK_0 MK_1 MK_2 MK_3$（各 32 bit），先异或系统参数：

$$K_i = MK_i \oplus FK_i, \quad i = 0..3$$

然后迭代生成 32 个轮密钥，用**完全相同的 T 结构，但 L 换成 $L'$**：

$$rk_i = K_{i+4} = K_i \oplus T'(K_{i+1} \oplus K_{i+2} \oplus K_{i+3} \oplus CK_i)$$

$$L'(B) = B \oplus (B \lll 13) \oplus (B \lll 23)$$

**FK（系统参数，实测确认）**：

| 常量 | 值 |
|---|---|
| FK₀ | `0xa3b1bac6` |
| FK₁ | `0x56aa3350` |
| FK₂ | `0x677d9197` |
| FK₃ | `0xb27022dc` |

**CK（固定参数）**：$ck_{i,j}$ = 第 $i$ 个字的第 $j$ 字节 = $(4i + j) \times 7 \bmod 256$

实测验证这条公式对全部 32 个 CK 成立：

> CK[0] = 0x00070e15   CK[31] = 0x646b7279
> CK 全部可由 (4i+j)*7 mod 256 生成: True ✅

> 记住 **13/23** 这两个移位量是密钥扩展的 $L'$，与加密用的 **2/10/18/24** 不同——这是区分 `T` 和 `T'` 的唯一差别，也是考试常考点。

### 2.4 标准测试向量（GB/T 32907，本机已核对）

密钥 = 明文 = `0123456789abcdeffedcba9876543210`，单块加密：

> 密文 = 681edf34d206965e86b3e94f536e4246  ✅ 与官方一致

⚠️ **坑**：`openssl enc -sm4-ecb` 默认做 PKCS 填充，对标准向量会输出 32 字节。取向量时必须加 `-nopad`：

```bash
openssl enc -sm4-ecb -nopad -K 0123456789abcdeffedcba9876543210 -in block.bin | xxd -p
```

## 3. 常见攻击

### 3.1 攻击一：ECB 结构泄露（最易命中）

ECB 下**每个块独立加密**，所以相同明文块 → 相同密文块。攻击者不需要密钥就能看出明文结构。

实测（`SM4-工作模式攻击-solve.py` 考点1）：

| 块 | 明文 | 密文 |
|---|---|---|
| 0 | `NAME=alice______` | `cce9e88c7941f37dcfab2aae42b2929b` |
| 1 | `NAME=alice______` | `cce9e88c7941f37dcfab2aae42b2929b` ⬅ 重复 |
| 2 | `NAME=bob________` | `80319d44a18d22c63a2827b5b5f6bbb8` |

**利用方式**：

- **块重排**：加密结果块可以任意换序，解密后明文对应换序（实测交换后明文顺序确实改变），可做权限字段搬运。
- **逐字节猜测**：构造 `prefix + 猜测 + suffix` 填满块边界，密文块与目标块比对，可在不知道密钥的情况下逐字节还原明文（ECB 版 oracle）。
- **cookie/权限字段**：`admin=false` 与 `admin=true_` 这类等长字段可整块替换。

### 3.2 攻击二：CBC 比特翻转（篡改前置块控制后置块）

CBC 解密：$P_i = D(C_i) \oplus C_{i-1}$。

所以**翻转 $C_{i-1}$ 的某个 bit，$P_i$ 的同一位置也翻转同一 bit**，而 $C_i$ 对应的 $P_i$ 其余字节不受影响；代价是 $P_{i-1}$ 被整体随机化（$D(C_{i-1})$ 变得不可预测）。

实测（考点2）：

> 原明文块2 = b'ole=guestXXXXXX\x00'
> 篡改 C1 第 4 字节（翻转 'g'^'G' 的差值）后：
> 块1 明文 = 随机乱码                <- 牺牲掉
> 块2 明文 = b'ole=GuestXXXXXX\x00'  <- 'g' -> 'G' 精确命中
> 块2 只改了目标字节: True ✅

**利用方式**：当明文是 `uid=1234;admin=0` 这类结构化数据时，只改一个字节就能篡改字段值。若首块（IV 可控时）也能改，则 IV 直接作为可调参数。

### 3.3 攻击三：OFB/CTR 密钥流重用（最高频）

OFB/CTR 把分组密码变成**流密码**：密钥流 $KS$ 只依赖 (key, IV)，与明文无关。

$$C = P \oplus KS$$

**同一 IV 用两次 → 同一密钥流**：

$$C_a \oplus C_b = P_a \oplus P_b \quad\Longrightarrow\quad P_b = C_a \oplus C_b \oplus P_a$$

只需知道**任意一组**明密文对，就能解出所有用同 IV 的密文。

实测（考点3）：

> OFB 密钥流 = 2677f46b09c122cc975533105bd4a22a2c103bee29b2693cdf
> A 明文 = b'card_num=6228480010301477'
> A 密文 = 4516860f56af57a1aa63012263e09a1a1c210bdd19835d0be8
> B 密文 = 4516860f56af57a1aa63012263e09a1a1c210bdd198b5005e6
> C_a ^ C_b ^ P_a = b'card_num=6228480010309999'  ✅ 解出 B 的明文

**OFB 与 CTR 的区别**（易混）：

| | 密钥流生成 | 特点 |
|---|---|---|
| OFB | $O_i = E(O_{i-1})$，$O_0 = IV$，反复加密 IV | 迭代反馈；IV 复用即密钥流复用 |
| CTR | $O_i = E(IV + i)$，计数器递增 | 可并行；计数器复用同样致命 |

两者 IV/计数器复用**攻击方式完全相同**。实测确认两者的密钥流不同（`ks_ctr != ks` 为 True），别混为一谈。

**识别方法**：密文长度 = 明文长度（无块对齐填充）、且题面出现 IV/nonce/counter → 优先怀疑流式模式。

### 3.4 攻击四：CBC padding oracle

若服务端把"填充错误"与"解密失败"区分反馈（不同错误码/时间/页面），就能**逐字节解密**：

- 构造 $C_{i-1}[j] = guess \oplus pad$，观察是否返回填充正确。
- 每字节 256 次尝试，一个块最多 $16 \times 256$ 次请求，整段明文可解。
- 也常被用来伪造合法密文（绕过 MAC 校验顺序不当的实现）。

防御：加 MAC 并**先验 MAC 再解密**（Encrypt-then-MAC），错误反馈统一。

### 3.5 攻击五：差分 / 线性分析（学术向）

- SM4 共 32 轮，目前公开的最好攻击覆盖 **23 轮**左右（如 2025 年对关键恢复友好的 19 轮差分特征的改进），全 32 轮**无实际可行攻击**。
- SM4 的高安全裕度来自 S 盒的高非线性度与 L 层的良好扩散。研究这类攻击需要大量选择明密文对（$2^{100}$ 量级），CTF 里不会出现，但**面试/答辩会问"SM4 安全吗"**。

### 3.6 攻击六：侧信道

- **缓存时序**：S 盒查表会泄露访问地址（与 AES 同类问题）。
- **功耗/电磁**：相关性功耗分析（CPA）可恢复轮密钥。
- 防御：用位切片（bitslicing）实现免查表。

## 5. 面试速答卡

**问：SM4 和 AES 有什么异同？**
答：同为 128 bit 分组、128 bit 密钥、128 bit 主密钥；都用 S 盒 + 线性扩散。**结构不同**：AES 是 SPN（替代-置换网络），SM4 是 32 轮非平衡 Feistel；AES 轮数按密钥长度 10/12/14，SM4 固定 32 轮。安全性同级。

**问：SM4 的 T 和 T' 差别在哪？**
答：只有线性层的移位量不同——加密用 $L(B)=B\oplus(B\lll2)\oplus(B\lll10)\oplus(B\lll18)\oplus(B\lll24)$；密钥扩展用 $L'(B)=B\oplus(B\lll13)\oplus(B\lll23)$。

**问：为什么 SM4 解密电路和加密一样？**
答：Feistel 结构逐轮可逆，解密只需把 32 个轮密钥**逆序**使用。

**问：ECB 为什么不能用？**
答：相同明文块产生相同密文块，泄露明文结构，且支持块重排攻击。应改用 CBC/CTR/GCM。

**问：CTR 和 OFB 都会密钥流重用，有什么区别？**
答：OFB 是反复加密 IV（迭代反馈，不可并行）；CTR 是加密递增计数器（可并行）。两者 IV 复用后果相同。
