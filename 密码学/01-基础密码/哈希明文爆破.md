# Python 哈希明文爆破

> 来源：题目给残缺明文模板 + MD5/SHA 哈希（或片段），穷举未知字符恢复明文。配套脚本 `hash-brute-force-solve.py`。

## 一、题型识别

- 给残缺明文，含 `?` 占位未知字符（如 `TASC?O3RJMV?WDJKX?ZM`）+ 哈希片段
- 只给一段哈希，提示"有 N 位未知字符"要爆破
- **本质**：哈希单向不可逆，但未知字符 ≤4 时可暴破可行

## 二、核心坑：hashlib 只吃 bytes

```python
m.update('TASC' + ...)              # ❌ Py3: TypeError: Strings must be encoded before hashing
m.update(('TASC' + ...).encode())   # ✅ 先 .encode()
```

- Py2 的 str 本质是字节，能直接喂；Py3 的 str 是 Unicode 文本，`update()` 只收 **bytes**
- 口诀：**hashlib 只吃 bytes，喂之前先 `.encode()`**
- 复刻老 writeup 时第一眼看 `update()` 参数类型

## 三、核心逻辑

### 1. 穷举范围

```python
range(32, 127)   # 空格(32) ~ ~ (126)，95 个可打印 ASCII；127 取不到（右开区间）
```

### 2. 模板填充 + 哈希 + 子串筛选

```python
import hashlib, itertools

TEMPLATE = 'TASC?O3RJMV?WDJKX?ZM'
PARTS = ['e9032', 'da', '911513']   # 哈希片段，取交集筛唯一解

def fill(template, vals):
    it = iter(vals)
    return ''.join(next(it) if c == '?' else c for c in template)

def matches(digest, parts):
    return all(p in digest for p in parts)

for combo in itertools.product(range(32,127), repeat=TEMPLATE.count('?')):
    plain = fill(TEMPLATE, (chr(i) for i in combo))
    h = hashlib.md5(plain.encode()).hexdigest()
    if matches(h, PARTS):
        print(plain, h)
```

### 3. `?` 填充的惯用技巧

用 `iter(values)` + `next(it)`：遇到 `?` 就从字符序列里取下一个，否则保留原字符。这样按顺序填满所有占位符。

## 四、规模判断（决定是否值得暴破）

| 未知字符数 | 穷举量（95^N） | 可行性 |
|---|---|---|
| 1–2 | ≤9 千 | 秒出 |
| 3 | ~86 万 | ~2s（实测 6.1s 含 95^3） |
| 4 | ~8 千万 | 分钟级 |
| 5+ | ~77 亿 | ❌ 换字典 / 彩虹表 / hashcat mask attack |

> 实测：本题 95^3 = 857,375 次，纯 Python 单线程 6.1s，唯一解 `TASCJO3RJMVKWDJKXLZM` → `e9032994dabac08080091151380478a2`。

## 五、易错点

| 坑 | 现象 | 解决 |
|---|---|---|
| update 收 str | `TypeError: ... must be encoded` | `.encode()` |
| 片段太短 | 多个解 | 增加片段，取交集 |
| 用全等判断 | 漏解（片段≠全哈希） | 用 `in` 子串匹配 |
| 字符范围 | 漏中文/特殊字符 | 按题目调整 charset |
| 未知字符 >4 | 跑不完 | 换思路（字典/彩虹表/hashcat） |

## 六、可扩展

- **换算法**：改 `hashlib.new('sha256', ...)`
- **换字符集**：`range(48,123)` 只数字+字母，量更小
- **提升速度**：`itertools.product` 换 `concurrent.futures` 多进程，或用 PyPy / hashcat

## 七、小结

1. 哈希不可逆，只能穷举未知的小片段。
2. 用 `?` 占位 + `itertools.product` 穷举 + 子串交集筛选。
3. hashlib 只收 bytes，先 `.encode()`。
4. 未知字符 ≤4 才值得暴破，更大换 hashcat/彩虹表。
