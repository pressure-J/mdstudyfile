# 古典的终点：希尔与分组思想的诞生

> **定位**：`古典密码1.md` 的收尾篇，也是通往对称密码的桥。
> 希尔（Hill，1929，Lester S. Hill）在分类上属于古典密码，但它同时是**第一个分组密码**和**第一个用线性代数构造的密码**——所以单独拆出来讲。
>
> **对应考点**：ISCC 2026 密码安全赛 模块 1「古典密码体制原理与通用分析方法」（希尔矩阵求逆）+ 模块 2 的入口（分组与扩散）。
>
> 本节所有数字均为 `crypto/29-希尔密码.py` 在本机实跑输出。

---

## 0. 为什么它算"古典"，却不像古典

| 判据 | 一般古典密码 | 希尔 |
|---|---|---|
| 处理单位 | **单个字母** | **n 个字母一组**（分组！） |
| 数学工具 | 频率统计、枚举 | **线性代数、模运算、矩阵求逆** |
| 扩散性 | 无（改一个明文字母 → 改一个密文字母） | **有**（改一个字母 → 整组密文全变） |
| 年代 | 手工/机械时代 | 1929，计算机之前，可手算 |

前两列它符合古典的定义（**字符为单位 + 手算可行**），第三列它已经提前用上了现代分组密码的核心思想。所以它是**古典的终点、现代的起点**。

---

## 1. 原理：一句话 + 一个公式

把明文按 **n 个字母一组**变成列向量，左乘密钥矩阵：

$$C = K \cdot P \pmod{m}, \qquad P = K^{-1} \cdot C \pmod{m}$$

传统字母版 `m = 26`（A=0…Z=25），字节版 `m = 256`。**n=2 最常见**，也最好打。

---

## 2. 唯一的硬门槛：可逆性

矩阵能求逆 ⇔ **`gcd(det(K), m) = 1`**。

| 模数 | 可逆条件 | 记忆点 |
|---|---|---|
| 26 | det 为**奇数**且**不是 13 的倍数** | 26 = 2 × 13 |
| 256 | det 为**奇数** | 256 = 2⁸，只要不是偶数 |

**这同时是判据**：题目给的密钥如果让 det 与 m 不互素，那它根本解不回去——要么密钥读错，要么还有一层。

实测：

```
密钥 K = [[3, 3], [2, 5]]   det = 9（与 26 互素 → 可逆）
明文 HELP → 密文 HIAT → 解密回 HELP
K⁻¹ (mod 26) = [[15, 17], [20, 9]]
```

---

## 3. 三种题型，三条路

### ① 给了密钥 → 直接算

```python
decrypt("HIAT", [[3, 3], [2, 5]])      # → 'HELP'
```

### ② 给了若干组明密文对 → 反推密钥

有 n 组 n 字母的块就够：**`K = C · P⁻¹`**（P 以明文块为列）。

实测：`recover_key([("HELP","HIAT"), ("COME",...), ("BACK",...)], 2)` → `K = [[3,3],[2,5]]`，与原密钥一致。

⚠️ 传进去的"对"会先按 n **切成块**再配对——`"HELP"` 给的是**两个** 2 字母块，不是一个。这里最容易写错。
⚠️ 挑到线性相关的块（det 与 m 不互素）要**换一组**，不能硬算。

### ③ 只给密文 → 暴力

n=2、m=26：全部 `26⁴ = 456976` 种，可逆的约 1/4（≈12 万）。枚举 + 明文可读性筛，秒级。

实测：从 `HIAT` 出发全空间枚举**只命中 1 个**密钥 `[[3,3],[2,5]]` → `HELP`。

n=3 时空间升到 `26⁹ ≈ 5.4×10¹²`，暴力不可行 → 必须靠已知明文或其他泄露。

---

## 4. 模 256 字节版

同一套矩阵运算，元素变字节、模数换 256：

```
det(模 256) = 9（奇数 → 可逆）
b'AB' → b'\x89\xcc' → b'AB'
```

常与"异或 + 编码"混出，密文是**原始字节而非字母**时优先怀疑它。

---

## 5. 关键教训：为什么现代密码不能只有线性

这是希尔最有价值的地方——它用**最小的代价**证明了线性变换不够：

> 已知 n 个明密文块（n = 分组长度），直接解方程 `K = C·P⁻¹`，
> **密钥一次算出，完全不需要暴力。**

也就是说：**纯线性密码在已知明文攻击下等于没有密钥**。

推论，也是现代分组密码的三条设计铁律：

| 必须有什么 | 为什么 | 希尔哪里缺 |
|---|---|---|
| **非线性**（S 盒） | 打断明文与密文的线性关系，让"解方程"失效 | 全是矩阵乘法，纯线性 |
| **多轮迭代** | 单轮扩散不彻底，多轮叠加才能雪崩 | 只有 1 轮 |
| **密钥扩展** | 单一密钥结构的代数关系太强 | 整段用同一个矩阵 |

## 6. 从希尔到 SM4 / AES：结构对应表

看清这张表，古典 → 对称这一跳就接上了。

| 概念 | 希尔（n=2） | SM4 | AES |
|---|---|---|---|
| 分组大小 | 2 字母（26² 种） | **128 bit** | **128 bit** |
| 密钥 | 2×2 矩阵 | 128 bit → 扩展成 32 个轮密钥 | 128/192/256 bit |
| 非线性 | ❌ 无 | S 盒（8 bit → 8 bit） | S 盒 |
| 扩散 | 矩阵乘法（一次全局） | 线性变换 L（循环左移 2/10/18/24，5 项异或） | ShiftRows + MixColumns |
| 轮数 | 1 | **32 轮** | 10 / 12 / 14 轮 |
| 结构 | 单次矩阵乘 | 广义 Feistel | SPN（代换-置换网络） |
| 解密 | 求逆矩阵 | **同一结构，轮密钥逆序** | 逆变换 |
| 已知明文 | **直接解出密钥** | 无法解出 | 无法解出 |

**一句话串起来**：
希尔用**矩阵乘法**做扩散 → 现代密码保留"扩散"这个思想，但把**单次线性变换**换成 **"S 盒（非线性）+ 线性层 + 多轮迭代"** 的组合。这就是从古典跨到现代的全部差别。

---

## 7. 易错点

- **非字母要先剔掉**：空格、标点、换行不参与向量。剔之前确认题目是不是按"字母流"分组。
- **长度不是 n 的倍数**：要么题目补过（问清用 `X` 还是 `Z`），要么你少读了字符。
- **大小写**：统一转大写再算，`m=26` 下没有小写。
- **把可逆条件当小事**：det 与 m 不互素时 `pow(det,-1,m)` 会抛异常——这是好事，说明题读错了，别 hack 它。
- **n=3 别硬暴力**：`26⁹` 跑不完，先找已知明文。
