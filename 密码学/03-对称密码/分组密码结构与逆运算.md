# 分组密码结构与逆运算

> **一句话本质**：分组密码 = 轮函数 × 32 轮；解密 = 逆变换 × 逆序。考题不考你实现 AES，考「给结构，能不能倒着走」——S 盒求逆、轮密钥逆序、密钥扩展逆推三板斧。
> 对应综述路径②；工作模式缺陷在《工作模式与配置缺陷》（已写），本文专注**块内部**。

---

## 0. 分组长度是算法参数，不永远是 16 字节

| 算法 | 分组长度 |
|---|---|
| AES / SM4 | 128 bit = 16 字节 |
| DES | 64 bit = 8 字节 |
| PRESENT（轻量级） | 64 bit = 8 字节 |
| 教学玩具 | 可以任意（我出过 16 bit = 2 字节的） |

分工三层：**分组密码**定块长和块内变换；**模式**拆消息、定块间关系；**填充**补尾巴。密文长度 mod 块长可反猜算法（任意长度原样 → 流式模式/流密码）。
⚠️ "一次只加一块"对，但块长看算法——别把 16 字节当教条（2026-10-24 我把 2 字节块的题当成错题，就是这条没吃透）。

## 1. 轮函数解剖（两类结构）

```
状态 → ① S盒代换(非线性,字节级) → ② P层扩散(线性,移位/换位/矩阵) → ③ ⊕轮密钥 → 下一轮
```

| | SPN（AES、SM4） | Feistel（DES） |
|---|---|---|
| 轮函数作用于 | 整个状态 | 一半，输出 XOR 给另一半 |
| 解密 | 每步求逆（S⁻¹、P⁻¹） | **不需要 F 的逆**（F 在两侧自抵消） |
| 解密轮密钥 | 逆序 | 逆序 |

**S 盒是唯一非线性来源**，本质是有限域求逆（AES 用 GF(2⁸) 的 0x11B）。没有 S 盒，整个密码是线性系统，解方程即破——非线性就是"为什么必须暴力/查表"的原因。

---

## 2. 核心定理：解密 = 逆变换 × 逆序

加密 `C = f3(f2(f1(P)))` → 解密 `P = f1⁻¹(f2⁻¹(f3⁻¹(C)))`，洋葱从外往里剥。

三条推论（题 C2 逐条用到）：

1. **轮密钥逆序用，密钥本身不求逆**——⊕k 的逆是 ⊕k 自己（自反性 x⊕x=0 的另一面）
2. **S 盒造逆表**：`SINV[S[x]] = x`，对表一遍循环。双射（每输出唯一对应一输入）是解密存在的数学前提
3. **P 层看自逆性**：换位类（两半对调）自逆，写一遍就是逆；移位/矩阵类要求逆移位/逆矩阵

## 3. 密钥扩展逆推——"漂亮的陷阱"

轮密钥生成是**同向递归 + 公开常量**。SM4 为例（GM/T 0002）：

```
正向: K_{i+4} = K_i ⊕ T'(K_{i+1} ⊕ K_{i+2} ⊕ K_{i+3} ⊕ CK_i)     rk_i = K_{i+4}
      K_0..K_3 = MK_i ⊕ FK_i
```

加密与密钥扩展是"表亲"（题 C3 吃透的对比表）：

| | 加密轮 | 密钥扩展 |
|---|---|---|
| 旧四字来源 | 明文 X_0..X_3 | MK ⊕ FK |
| 轮常数 | rk_i（自产） | CK_i（公开硬编码） |
| 非线性 | T = L∘τ，L 移 2/10/18/24 | **T' = L'∘τ，L' 只移 13/23**（唯一差别） |
| 产出 | 密文（X_35..X_32 倒序取） | 32 个轮密钥 |

**倒推公式**（已知链尾 4 个 → 推回全部）：

```
K_i = K_{i+4} ⊕ T'(K_{i+1} ⊕ K_{i+2} ⊕ K_{i+3} ⊕ CK_i)      i 从 31 降到 0
MK_i = K_i ⊕ FK_i
```

**两个"为什么"（考点核心）**：
- **T' 不用求逆**：倒推到第 i 步，T' 括号里的 K_{i+1}..K_{i+3} + CK 全是已知量，S 盒**正向查表**。逆推 32 步，非线性永远站在"已知"一侧
- **逆推靠 ⊕ 移项，不靠 T' 可逆**：⊕ 自反性让"移项"="再异或一次"，T' 全程当黑盒正着调

**判据（通用）**：给部分轮密钥反推主密钥这类题，先看"逆推方向上每一步的非线性输入是否全部已知"——是，则线性移项打通；否（如 AES-256 后半轮密钥依赖的量在前方），才需要真求逆/另找路径。

## 4. 例题复盘（2026-10-24 手撕训练，`D:\python\homework\对称密码手撕\`）

| 题 | 内容 | 我的解法 | 踩的坑 |
|---|---|---|---|
| C1 | PRESENT 4-bit S 盒求逆 | 对表一遍生成逆表，16 项全验 | 无 |
| C2 | 16-bit 玩具轮密码逆序解密 | ⊕K2→S⁻¹→⊕K1→对调→S⁻¹→⊕K0 | ① 16-bit K 直接 XOR 4-bit nibble，下标越界——K 也要切 nibble 对位异或；② 对调写成值内位旋转——位置换动**下标** `[n[2],n[3],n[0],n[1]]`，不是动值；③ 把"每 nibble 独立跑全程"当"整块分步"——流程要按块串联 |
| C3 | 真实 SM4 密钥扩展逆推 | 链尾 rk_28..31 → 倒推 K_31..K_0 → MK = K⊕FK → 解密 | 加密流程没吃透就动不了——退回来先啃 T/T'/FK/CK 的对比表，再写一遍就通 |

**诊断口诀**（B/C 两组通用）：代码报错/输出乱码 → 先查**已知条件假设**（明文对不对、K 切没切块），再查**步骤顺序**（逆序对不对），最后查**实现细节**（位宽、下标）。

## 5. 学到什么算过关 + 30 秒自查

**过关线**：给任意轮密码结构，能在纸上写出解密流程（逆序+每步取逆）；给 S 盒能造逆表；给链尾轮密钥能倒推主密钥并能说清"为什么 T' 不用逆"。

| 现象 | 先想 |
|---|---|
| 题面给轮函数代码 + 部分轮密钥 | 密钥扩展逆推（本文 §3） |
| 题面给 S 盒 + 多轮结构 + 密文 | 逆序剥层（§2），先造 S⁻¹ |
| 给"加密一半再换位"的结构 | Feistel，解密不需 F 的逆（§1） |
| 逆推时卡在非线性 | 检查非线性输入是否全已知——已知则正向查表即可 |
| 结果乱码但代码不报错 | 位宽截断（& 0xFFFFFFFF）或 K 没按块宽切 |
