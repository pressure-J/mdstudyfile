## 05-国密

> 国产商用密码 SM2/SM3/SM4。**先看速通卡**（15 分钟版，只讲攻击不讲原理），需要细节再看三篇专篇。

| 笔记 | 触发特征（看到就用） |

| [国密速通卡](05-国密/国密速通卡.md) | **入门先看这篇**：三个算法各一句话认知、三大攻击（SM4 密钥流重用 / SM2 k 重用 / SM3 长度扩展）、**三步判断法**（改 1 字节看密文扩散范围定模式）、四行命令、何时才需翻专篇。**不含算法内部细节** |
| [国密算法总览](05-国密/国密算法总览.md) | 体系总表、按题面特征秒查表、公共工具链、公共踩坑速查 |
| [SM2-椭圆曲线公钥算法原理与攻击](05-国密/SM2-椭圆曲线公钥算法原理与攻击.md) | 要给两组签名的「随机数缺陷/同一 k」→ k 重用直出私钥（**SM2 公式是 `d=t/(1−t)`，照抄 ECDSA 必错**）；两次加密 **C1 相同** → 加密 nonce 重用；曲线 a/b/G 非标准或服务端不校验点 → 无效曲线/小阶子群。含 ZA 身份哈希、C1C3C2 密文序、**OpenSSL 密文是 DER 不是裸结构** |
| [SM3-杂凑算法原理与攻击](05-国密/SM3-杂凑算法原理与攻击.md) | `digest = SM3(SECRET \|\| data)` 要伪造 → **长度扩展攻击**（填充分两处、长度要爆破）；给两个消息要同摘要 → 碰撞仅学术可行。含 64 轮压缩函数、68 个 W + 64 个 W′、P0/P1 与两个轮常数 |
| [SM4-分组密码原理与攻击](05-国密/SM4-分组密码原理与攻击.md) | 同 IV 的 OFB/CTR 两段密文 → **密钥流重用 `C_a⊕C_b⊕P_a=P_b`**；密文有重复块 → ECB 结构泄露/块重排；有填充报错反馈 → CBC padding oracle；改前一块密文精确控后一块明文。含 32 轮非平衡 Feistel、T/T′ 的移位量差异（2/10/18/24 vs 13/23）、FK/CK 常量 |

| 脚本 | 依赖 | 用途 |
|------|------|------|
| `SM2-随机数k重用攻击-solve.py` | gmssl | 两组签名反推 x1 判定 k 重用 → `d = t/(1−t)` 恢复私钥（**注意 SM2 不能照抄 ECDSA 公式**）；末段跑 ECDSA 错公式做反例 |
| `SM3-长度扩展攻击-solve.py` | gmssl | 爆破 SECRET 长度（0..63）→ 从内部状态续压，伪造 `SM3(SECRET‖data‖padding‖append)` 合法摘要 |
| `SM4-工作模式攻击-solve.py` | gmssl | 三个考点：ECB 重复块与块重排、CBC 比特翻转精确控字节、OFB/CTR 密钥流重用；gmssl 无 OFB 接口，脚本内用 `one_round` 自实现 |
